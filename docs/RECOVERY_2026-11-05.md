## 本轮新增数学推进

对十五阶六次单位根矩阵，PDF 中的能量下界是 9。本轮完整排除了 Q=9 和 Q=10，得到 **Q≥11**。孤立点情形覆盖 264 种无叶支撑、343,158 个标号状态、1,759 种平坦核必要条件记录；Q=9、10 分别有 285、1,402 个组装，范数与同谱筛选后的 29、124 个双侧组合全部违反有理框架约束。Q=9 无孤立点情形用树行列式及三角形—配对谱矩形排除；Q=10 的 74 个无孤立点组装也全部排除，两个范数存活者的同谱配对均违反整数谱矩形。

于是

```math
5\cdot2^{26}\sqrt3\le D_6(15)\le
\left[(15-\sqrt{11/105})^{14}(15+14\sqrt{11/105})\right]^{1/2}.
```

除以 Hadamard 上界后，上端从约 **0.9829570878** 降到 **0.9794997502**。这是相对于提供的 PDF 的严格加强；没有宣称六次单位根精确最大值已解决。

## 复现与文件

安装 `proof/requirements.txt` 的固定依赖，使用 Python 3.11 与 C++17：

```sh
python verify_all.py
```

该命令先重建原证明目录，再运行 `verify_continuation.py`。后者也可在原目录已重建时单独执行。所有证书位于 `data/revision/`，详细覆盖说明见 [extensions/README.md](../extensions/README.md)。生成摘要会先标记未完成，全部通过后才写入成功状态及 SHA256，避免中断后误读旧状态。

`make paper` 编译论文，`make arxiv` 打包全部 LaTeX 源。已修正列计数表和 25 阶矩阵的超宽，保留作者单位与一句 AI 声明，并更新历史说明中已过时的“尚未分类”状态。

PDF 中用于寻找 25 阶矩阵的 78 类设计普查、50 个符号系统及旧搜索过程，不是当前存在性证明的依赖，本次没有据 PDF 文字虚构这些原始档案。当前稿使用显式矩阵与直接验证替代这部分发现记录。51 阶全局最大性、称重族的无限性、十五阶六次单位根的精确最大值，以及无限同余族的二次能量间隙仍未解决。
