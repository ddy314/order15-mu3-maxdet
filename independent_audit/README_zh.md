本包包含原始归档、重新编写并实际运行的精确验证程序、全部允许 Q 的状态表、运行日志和证明说明。**本包尚未证明全局最大值等于纪录值。** 原归档 ledger 的 `CLOSED` 被保留为历史声明；它不决定新复核表的状态。

## 当前可核实的结论

纪录矩阵通过三条精确计算路径：在 Eisenstein 整数环上用 Bareiss 消元计算 det(H)，用有理数高斯消元独立计算 det(H)，以及直接计算 det(HH*)。结果均给出 B=277868041444786176=2^22·3^20·19，矩阵的行、列能量均为 Q=105。它证明最大值至少为 B；它本身不证明全局上界。

38 个需要考虑的壳层中，已完成 Q≤81 的全部19个：0,6,9,15,18,24,27,33,36,42,45,51,54,60,63,69,72,78,81。其中42,51,60,69,78,81使用了 Todorov–Bogdanova (2020) 的已发表定理 B_3(15,10)=12；本包没有重跑该论文的码分类。其余低能量结论通过本包中的图支撑枚举、精确范数筛、谱和核投影不等式重建。图同构代表依赖 NetworkX 的图册与树生成器。

另有几项完整的局部分支结果：Q=99 的 A/B、A/A、B/B 局部交织矩阵已由独立线性方程消元重新枚举，分别为144、225、729个，残差兼容者均为0；Q=105,114,123,132,141,150,159,168 的 (14,1) 型内部无孤立顶点分支，全部36种内部能量分配均已达到纪录级上界。上述局部结果不自动关闭整个壳层。Q≥171 的全部情况由精确有理数迹—方差界排除；Q模9不属于{0,6}的情况由同余排除。

仍未完整验证的19个壳层为：87,90,96,99,105,108,114,117,123,126,132,135,141,144,150,153,159,162,168。它们的具体缺口写在 `results/all_Q_audit.json`、`results/all_Q_audit.csv` 与报告中。`UNVERIFIED_GLOBAL` 表示尚无完整复核证据，不表示已找到反例，也不表示原数学结论一定错误。

## 一次性运行

需要 Python 3.11 或更高版本；本次实际环境及版本写在 `results/replay_summary.json`。使用 `python -m pip install -r requirements.txt` 安装固定依赖，然后在此目录运行：

```bash
python run_all.py --audit-only
```

这个命令重跑全部现有验证、输出原始日志，并重新生成每个 Q 的状态表。`--audit-only` 的成功仅表示现有复核项目运行成功。直接运行 `python run_all.py` 时，只要还有未验证的壳层，就以退出码2结束，防止把局部测试成功误读成全局定理成功。断言必须启用；禁止 `python -O`。
