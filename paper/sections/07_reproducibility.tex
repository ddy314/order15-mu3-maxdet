\section{Reproducibility and scope}\label{sec:repro}
The maintained source, exact matrices and certificates are available at
\url{https://github.com/ddy314/order15-mu3-maxdet}.
Use Python 3.11 and a C++17 compiler, with assertions enabled:
\begin{verbatim}
python -m pip install -r proof/requirements.txt
python verify_all.py
\end{verbatim}
The original replay regenerates the component catalogues before the inclusive equality audit reads them. The continuation may then be rerun separately using \file{verify_continuation.py}. Every certificate is regenerated; an interrupted replay leaves its summary marked incomplete.

\begin{longtable}{@{}p{.28\textwidth}p{.66\textwidth}@{}}
\toprule Obligation&Exact replay\\\midrule\endhead
Original maximum&\file{proof/run_final.py}: all 38 coarse energies, two exhaustive column algorithms on the final 194 Grams.\\

Fano factor classes&\file{tools/verify_fano_completions.py}: all 792 column count types, all 675 potential patterns and exhaustive quadrangle control; \file{tools/verify_continuation.py}: all 141 potential patterns, nine orbits and matrix representatives.\\
Explicit constructions&\file{tools/verify_continuation.py}: both-sided integer weighing identities, order-51 Eisenstein determinant and independent 102-dimensional integer determinant; sixth-root witness and independent 30-dimensional determinant.\\
Sixth-root improvement&\file{extensions/sixth_roots/verify_gap.py}: all 100 leafless supports and 51774 labelled states at energy at most nine; frame, norm and rectangle obstructions.\\\bottomrule
\end{longtable}
These are computer-assisted proofs, with the analytic reductions stated in the text. The published difference-matrix theorem is independently reproduced here. The ordinary equidistant-code parameter is retained as background to the historical 29-shell reduction. The support census used during discovery of the order-25 signing is unnecessary for the displayed existence certificate. Global maximality at order 51, an infinite weighing family, the exact sixth-root maximum, and a quadratic energy gap in an infinite congruence class remain open in this work.
