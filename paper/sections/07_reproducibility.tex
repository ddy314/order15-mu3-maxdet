\section{Reproducibility and scope}\label{sec:repro}
The verification programs and exact data are available in the companion repository at
\url{https://github.com/ddy314/order15-mu3-maxdet}.
The programs under \file{proof/} generate the finite catalogues and verify the 38 coarse energy shells. The program \file{tools/verify_sharp_reduction.py} checks the reduction to 23 energies and the corresponding exclusion witnesses. Exact matrix data are stored under \file{data/}; \file{tools/verify_structure.py} verifies the extremizer and its automorphism group.

The complete verification is run from the repository root with
\begin{verbatim}
python -m pip install -r proof/requirements.txt
python verify_all.py
\end{verbatim}
The three stages may also be run separately:
\begin{verbatim}
python proof/run_final.py
python tools/verify_sharp_reduction.py
python tools/verify_structure.py
\end{verbatim}
Python assertions must remain enabled. The last command requires a C++17 compiler for the exhaustive automorphism enumeration.

The 38-shell verification includes two complete normalized-column scans for each of 194 Gram candidates. Each scan examines $3^{14}=4{,}782{,}969$ columns. These scans provide additional checks: the 23-shell proof excludes all 194 candidates by the orthogonality bound, using explicit independent sets of at least ten vertices. The sharp-reduction verifier reconstructs each Gram, checks its determinant, and supplies the independent-set witness.

The analytic and algebraic arguments are proved in the text. The finite support, norm, phase, and coefficient families are generated and checked by the repository programs. The results $B_3(15,10)=12$ and $M_3(15)=9$ are published external classifications; they are cited rather than regenerated here. This is a computer-assisted mathematical proof, not a proof-assistant formalization. It neither classifies all maximizing equivalence classes nor establishes the asymptotic hypothesis of \cref{cor:gap}.
